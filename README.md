主要结论：

- 该包是带未提交修改标记的 Linux ARM64 Go 程序，不包含可确认与该二进制完全一致的原始应用源码。
- 知识库不是单纯的数据库页面：存在检索、取用、复用记录、运行前参考块、Agent 工具和发现回填入口。
- WebShell、C2、远程会话、隧道、内网拓扑、VPS 和临时文件分发具有专用实现证据，不能用一个“连接登记”页面替代。
- 存在 Skill 预查和按意图选择工作流参考的模块；仅复制 Skill 文件不能保证调用逻辑一致。
- ARM64 发行包混有 x86/x86_64 工具；文件存在不代表能在目标架构运行。
- 已取得 **168 个选定函数**的伪代码和 **37 个命名结构体**的恢复结果，不能称为“完整源码已恢复”。

公开范围：不含原始二进制、工具包、知识库正文、目标数据、配置凭据、应用源码或反编译执行代码。原始反编译材料未在本仓库重新分发，公开索引可以核对分析覆盖范围。本仓库也不是软件发行、部署或漏洞效果证明。
