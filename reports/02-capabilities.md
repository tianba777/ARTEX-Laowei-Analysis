# 功能总表

证据等级：**结构／符号**表示发现了函数、字段或页面；**选定伪代码**表示部分函数体已恢复并检查；两者都不是动态运行证明。

| 模块 | 观察到的能力范围 | 证据与限制 |
| --- | --- | --- |
| 知识库 | 管理、分类检索、全文／元数据匹配、读取正文、正负参考分组、复用记录 | 字段、SQLite、函数及选定伪代码；排序效果未实测 |
| 知识运行接入 | `kb_search/get/add`、`KBPreflightBlock`、发现回填、知识整理 Agent 注册 | 工具及预查／回填部分伪代码；各角色全部触发位置未穷尽 |
| Skill 预查 | Planner/Worker 的专门预查入口 | 目前主要是符号证据；不等于已还原全部选择规则 |
| 工作流参考 | 按意图分类选择 skeleton／refs，相关提示与验证清单 | `agent/chainskel` 及选定伪代码；不是证明自动攻击链已跑通 |
| WebShell | 登记、更新、检查、远程执行／文件操作、传输适配 | 专用 session 实现、页面、字段和管理函数；未验证端到端兼容 |
| 会话专属对话 | WebShell/C2 关联对话、历史和上下文绑定 | 管理函数和部分对话创建伪代码；实际工具装配仍有待核实的连接 |
| C2 | 监听器生命周期、会话登记／状态、任务、结果、文件和事件 | Manager、Store、数据结构、管理函数及部分伪代码；未执行协议验证 |
| 统一会话 | 注册表、持久化、恢复、状态与资产关联 | Registry/SessionStore/HTTPShell 等；不等于完整源工程 |
| Penelope 接入 | 进程／MCP 连接、会话同步和注册 | 专用 Handler 符号；实际配置、错误恢复和工具兼容未实测 |
| 隧道 | 计划、探测、部署、验证、健康检查、重部署、撤销及清理 | Tunnel Manager/Plan/Probe 类型与函数；无部署或真实连通测试 |
| 内网操作台 | 会话与文件操作入口、隧道／凭据列表、拓扑聚合 | 嵌入页面、handler 及选定伪代码；不能由页面存在推断成功率 |
| 内网信息解析 | 网卡、路由、邻居、hosts、连接表解析与推断 | `recon` 的解析／推断选定伪代码；没有真实主机验证 |
| Worker 内网接入 | `SetIntranetResolver`、`intranetForTask` 等运行绑定点 | 接入符号可确认；完整选择和失效回收流程尚未逐段恢复 |
| Stage 临时分发 | 内容／文件登记、临时下载、事件、删除和回收 | 专用 Manager 与分享工具入口；没有发布或下载执行测试 |
| VPS 管理 | 配置管理、连接与出口检查、专用执行入口 | VPS handler 和工具符号；不代表全部凭据类型均已验证 |
| 提示词预设 | 全局和按角色开关、预设管理与应用 | defaults 和 Armor 管理符号；不发布预设正文 |
| 登录与事件流 | 登录续期、退出、SSE 票据签发／消费入口 | 路由候选和专用符号；完整会话撤销语义未动态核实 |
| 工具清单校验 | 工具清单加载、检查和文件指纹函数 | 专用 `tools` 与 `checkToolsManifest` 符号；启动实际挂接细节未完整验证 |
| 特征判断 | 专门的 honeydetect 判断模块 | 仅确认模块及 Evaluate 等入口；效果、误判和挂接范围未知 |

[符号索引](../evidence/application-functions.tsv)和[选定恢复覆盖](../evidence/decompiled-function-index.tsv)供查证名称及覆盖范围，不发布执行实现、载荷或规避方法。
