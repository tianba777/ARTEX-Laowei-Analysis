# 与自有版本的差异快照

比较日期 2026-11-08。自有版本基准包含当日本地尚未提交的知识库和人工运维管理改动，不代表当时线上部署状态。本章不提供该项目源码或内部运行数据。

## 缺少专用执行子系统

| 老魏模块 | 自有版本当日状态 |
| --- | --- |
| WebShell 连接、执行、文件、专属对话 | 未实现该专用子系统 |
| C2 监听、会话、任务和回传 | 未实现该专用子系统 |
| 统一远程会话对象、恢复与资产关联 | 有人工元数据登记，没有对应连接／执行层 |
| Penelope 同步和专用接入 | 没有专用适配；通用 MCP 不能视为等价 |
| 隧道计划、探测、部署、健康和清理 | 只有连接记录，没有实际生命周期执行 |
| 内网会话操作台、解析和会话拓扑聚合 | 有原资产／任务能力，没有同套远程会话联动 |
| Worker 内网执行环境绑定 | 没有对应的会话／隧道执行接入 |
| Stage 临时内容分发 | 没有同套专用服务；工作空间下载不等价 |
| VPS 专用管理和执行 | 有 SSH 信息登记，没有该专用管理／连接执行链 |

自有版本当前链路为：登记 → 人工申请 → 既有人工审批 → 操作人自行处理 → 人工回报与审计；不建立连接、不自动执行。不能把“已批准”或“人工报告完成”解释成远程平台执行成功。

## 知识和工作流仅部分对齐

- 有创建／导入、采纳、检索、取用和候选回填闭环；不是老魏全部调用逻辑的逐行移植。
- 当前预查使用任务描述＋目标，只在四类内置 Agent 中接入、默认关闭，开启后最多注入六条索引；未逐入口对齐老魏输入和触发方式。
- Agent 检索只暴露关键词和分类；管理端支持更多筛选，但语言、来源、行动／资产等不是全部独立筛选维度。部分数据仅作为元数据保存。
- 有自身相关性排序及结果分组，没有复刻原全部评分、猜测和简报规则。
- 没有专门的知识整理 Agent；发现候选回填不能等同于独立整理流程。老魏该 Agent 的完整触发范围本身也未核实。
- 导入数据库正文，不自动读取旧 path，不自动引入外部资料和依赖。
- Skill 可见性、加载、MCP 解锁已存在，但没有对齐专门 Skill 预查及 chainskel 的按意图参考选择。

## 数据、默认设置及其他差异

448 条旧库记录和整套工具／Skill 未导入。导入会保留来源声明并降为候选，不把旧 verified 当作本地核验。自有补充预设不包含老魏预设文本；既有审批、提示词和模型绑定保持原策略，没有应用老魏默认放行配置。

另发现登录续期／退出、SSE 一次性票据、工具清单校验、专门特征判断等入口差异；这些模块在老魏侧也没有完整动态效果证明。

自有版本仍具有原有通用 MCP、交互式 Shell、任务图、资产、模型绑定及审批能力。专用适配缺失不能被误写成这些通用能力全部不存在。文件更多也不证明功能更有效，不能根据当前静态证据给出可信的移植完成百分比或效果排名。
