# 知识库专项

## 数据规模

只读查询确认 `poc` 表共 **448 条**。其中 382 条 `content` 非空，382 条 `path` 非空；本次样本没有“正文为空而 path 非空”的记录。因此不能说其知识全部依赖外部文件。

来源分布是数据库记录本身的声明：self 403、web 27、manual 17、code-audit 1。378 条标记 verified、70 条未标记；**本次未复验，378 不是本报告确认有效的数量**。

分类和语言等完整计数见 [knowledge-statistics.json](../evidence/knowledge-statistics.json)，不公开正文、来源 URL、行动名称、目标或核验说明。

## 数据层

字段包括稳定 code、标题、类型、分类、CVE、组件、版本、严重程度、语言、来源、来源 URL、描述、usage、正文、文件路径、verified 及说明、hit_count、used_on、行动／项目、资产目标、发现 Agent、标签、创建人和时间。

SQLite 记录字段与运行时反射类型不同：运行类型还出现 Polarity、Score、HasContent 等字段。不能把运行类型的全部字段认定为样本 SQLite 中都存在独立列。

## 检索与结果

`SearchOptions` 包含关键词、多个分类、类型、verified、标签、组件、CVE、行动／项目、资产目标、语言、来源、正负类型、结果上限及正文检索开关。

发现提取词、FTS／查询、评分与过滤、Brief/ResultJSON 等实现。结果结构区分 Ammo、Playbook、Negative，另有统计和提示。相关性效果和全部权重未通过统一样本对照验证，不把简单全文检索视为完全等价。

## 正文与复用

Get 支持计次取用和 UsedOn 参数；还存在路径解析、边界检查和外部资料读取函数。哪些调用仅浏览、哪些取用计次，需结合具体调用入口判断，不能只看 Get 的存在。

## 运行时接入

有三个知识工具、独立预查块、发现回填入口、分类／正负猜测函数及知识整理 Agent 注册入口。已恢复知识工具、预查和回填中的选定函数，完整覆盖范围以 [恢复索引](../evidence/decompiled-function-index.tsv)为准。

本报告不声称所有对话都会调用知识库，不声称每轮都会按当前资产重新查询，也不声称模型能自动正确选取条目。知识正文、验证标签、工具授权和当前任务的执行批准必须分别看待。
