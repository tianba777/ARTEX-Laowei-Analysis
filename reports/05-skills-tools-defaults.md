## Skill 组织

`skills/` 的分析清单包含 127 个文件，其中 13 个路径以 SKILL.md 结尾、34 个是顶层 Markdown；其余含参考资料和脚本。不能把文件数直接宣传为技能数量。

另有 `redteam/skills/` 平铺资料目录。主题覆盖侦察、应用分析、资产关联、代码审查、云、会话、隧道和工作流参考等。`chains-*` 目录中存在按领域组织的 refs。目录形态不同，是否由同一加载器识别应分别验证。

公开 [skill-paths.json](../evidence/skill-paths.json)只列相对路径和大小，不公开资料正文、攻击脚本或运行内容。

架构检查发现 x86、x86_64 和 ARM64 混装，详见 [tool-architectures.json](../evidence/tool-architectures.json)。未运行安装脚本，未下载依赖，未测试工具启动或扫描效果。

存在专门工具清单加载、文件校验函数以及清单检查入口；工具清单与启动挂接是否覆盖全部外部命令，尚未完整验证。

## 初始化和默认配置

包中的启动说明和 SQL 显示，部署者默认配置涉及提示词预设、全局／按角色开关和拦截配置。附带 README 对预设数量的说明与实际 SQL 应分开看，不能用说明中的数量当作数据库实测。

这些默认配置会影响运行行为。将知识库、Skill 或工具文件复制过去，不会自动复制所有设置；直接应用 defaults 又可能改变既有提示词和审批策略。本次没有运行 SQL、启动或安装脚本。

本仓库不公开“破甲”提示词正文、默认放行规则、载荷或规避流程。这里只记录存在性和对能力对比的影响。
